# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for a security problem. Use GitHub's private reporting instead: on this repository open the **Security** tab and choose **Report a vulnerability**. Include what you found, how to reproduce it, and the device or browser if it matters.

We will acknowledge your report and keep you updated while we look into it.

## What is in scope

- The game (`game/`), including the iOS and Android apps.
- The website (`site/`).

Binaroo has no accounts, no server and no backend, and it stores only four small settings on the device (best score, sound, haptics and theme), so the most likely issues are in the web code or in a dependency.

## Supported versions

Only the latest release and the current `main` branch receive fixes.
